# Maintained Skill Catalog

| Skill | Use in job-utils |
| --- | --- |
| `grilling` | Resolve ambiguous requirements and design decisions. |
| `research` | Capture findings from primary documentation and standards. |
| `domain-modeling` | Keep domain vocabulary and boundaries coherent. |
| `codebase-design` | Review module seams, interfaces, and dependency direction. |
| `prototype` | Test an uncertain design with a small disposable experiment. |
| `writing-plans` | Turn a confirmed requirement into an executable plan. |
| `executing-plans` | Execute a written plan with checkpoints and verification. |
| `tdd` | Drive behavior changes from focused tests. |
| `diagnosing-bugs` | Investigate regressions and failures systematically. |
| `coverage-analysis` | Assess whether tests exercise the important paths. |
| `requesting-code-review` | Review a substantial change before integration. |
| `differential-review` | Review diffs for security and regression risk. |
| `verification-before-completion` | Require evidence before declaring a change complete. |
| `sanitize-artifacts` | Remove process residue from user-facing documents. |
| `finishing-a-development-branch` | Decide how a verified feature branch is handed off. |
| `writing-skills` | Create or revise a reusable skill when the project needs one. |

Skill names can differ between Codex, GitHub Copilot, Claude, and other agent
hosts. Treat this table as the project-level intent; map a local tool's name to
the closest maintained role instead of installing a duplicate automatically.
