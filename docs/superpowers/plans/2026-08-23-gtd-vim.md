# GTD Vim and Python Core Implementation Plan

## Goal

Implement the shared GTD Markdown parser and dispatcher, then expose it through
a small Python CLI and a Vim command compatible with the attached Vimrc.

## Scope

- Parse and normalize `gtd.md` sections and prefixed list items.
- Support `next`, `today`, `focus`, `wait`, `cal`, `someday`, `project`,
  `pointer`, and `done`.
- Reject Inbox as a destination and enforce a maximum of three Focus items
  before any file mutation.
- Preserve stable UUID-backed task links and create a detail file for an
  unlinked non-`done` item on first successful dispatch.
- Synchronize task front matter and the task title heading.
- Provide `python -m jobutils gtd dispatch` and a Vim `:Gtd` wrapper.

## Files and interfaces

- Create `pyproject.toml` with a Python 3.8-compatible standard-library core.
- Create `src/jobutils/__init__.py`, `src/jobutils/__main__.py`, and
  `src/jobutils/cli.py`.
- Create `src/jobutils/gtd/model.py`, `parser.py`, `frontmatter.py`, and
  `dispatcher.py`.
- Create `vim/plugin/jobutils_gtd.vim` and `vim/autoload/jobutils/gtd.vim`.
- Create `tests/test_gtd_parser.py`, `tests/test_gtd_dispatch.py`, and
  `tests/fixtures/gtd_repo/`.

## Verification

- Unit-test section parsing, unprefixed repair, link parsing, front matter,
  arbitrary transitions, Inbox rejection, and Focus overflow atomicity.
- Run the CLI against a copied fixture and compare the resulting Markdown.
- Run Vim in Ex mode where available to source the plugin and invoke the
  wrapper against a fixture.
- Run `python -m unittest discover -s tests` and `git diff --check`.
