# Project Context

## Purpose

job-utils supports a personal GTD and work-document workflow built around
Markdown, Vim, Git, Jira, and Confluence.

## Canonical terms

- **job-utils Repository**: the repository containing the utilities and their
  supporting documentation.
- **GTD Repository**: the separate repository containing the user's tasks,
  documents, indexes, and activity data.
- **Inbox**: captured input that has not yet been clarified and assigned a
  meaningful destination.
- **Next**: an actionable next step that can be performed.
- **Today**: work selected for execution today.
- **Focus**: work currently being executed; up to three items may be active at
  once.
- **Waiting**: work paused because another person, system, or external event
  is required.
- **Calendar**: work associated with a scheduled date or time. It is not
  waiting time.
- **Someday**: work intentionally deferred without a current commitment.
- **Project**: an outcome that requires more than one action.
- **Done**: completed work.
- **Task Markdown**: a Markdown file representing a task or project item.
- **Document Markdown**: a Markdown file representing publishable or
  reference material.
- **External identity**: the stable Jira issue key/id or Confluence page id
  associated with a Markdown entity.
- **Sync plan**: a read-only description of proposed external changes.
- **Sync apply**: execution of an approved synchronization plan.
- **Metric event**: an immutable record of a meaningful task or synchronization
  occurrence.

## Vocabulary rule

The English values used in front matter and machine-readable data are stable
identifiers. User-facing Vim and review displays may use clearer Japanese
labels.
